# Day Counter

Displays the current Minecraft day in a configurable HUD.

Day Counter shows how many days have passed in your world directly on screen, so you no longer need to open the statistics screen. It is **client-side only** and **does not change any gameplay**. Features include:

- Showing the day as "Day 12", as a plain number, together with the in-game time, or as custom text with `{day}` and `{time}` placeholders.
- A 24-hour or 12-hour clock.
- A bed icon next to the hotbar or the counter when you can sleep.
- A freely movable HUD with adjustable size, text color, text shadow, background and border.
- Toggling the HUD with a key (`H` by default).

The settings can be opened with `/dc config` or, on Fabric, through Mod Menu. `/dc help` lists all other commands. Looking for the Day Counter datapack? It has moved to its [own project](https://modrinth.com/datapack/aviesdaycounter-datapack).

Pre 2.0.0 versions: [Avies Archive](https://avie.cc/archive/)

Bugs and crashes can be reported in the [issue tracker](https://github.com/avie293/avie-issues/issues) by selecting **Day Counter** as the project.
