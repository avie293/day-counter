## Day Counter

Display the current Minecraft day in a configurable on-screen HUD. This client-side Fabric mod is ideal for keeping track of your world without opening the statistics screen.

### If you searching for the Day Counter Datapack. It moved to new [Project](https://modrinth.com/datapack/aviesdaycounter-datapack).

### Features

- Choose between the day, a number, day and in-game time, or custom text with `{day}` and `{time}` placeholders.
- Adjust the HUD position, scale, text color, shadow, background, and border.
- Toggle the HUD with a configurable keybind.

Requires [TabbyLib](https://www.curseforge.com/minecraft/mc-mods/tabbylib/)
